# Tarunjit Saha — Portfolio

A modern, professional portfolio website for Tarunjit Saha, ML Engineer.

## 🗂 File Structure

```
portfolio/
├── index.html          # Home / Hero page
├── about.html          # About + Skills
├── projects.html       # All projects with filter
├── experience.html     # Work experience + Certifications
├── contact.html        # Contact form + channels
├── styles.css          # All styles (single file)
├── scripts.js          # All JavaScript (single file)
└── README.md
```

## ✨ Features

- **Custom animated cursor** with smooth follower
- **Loader animation** on first page load
- **Typing animation** cycling through roles
- **Scroll-reveal animations** for all sections
- **Animated skill bars** triggered on scroll
- **Animated number counters** (experience page)
- **Project filter tabs** (All / Generative AI / ML / Web)
- **Mouse parallax** on background orbs
- **Sticky, blur-backdrop navbar** on scroll
- **Working contact form** via Web3Forms
- **Fully responsive** — mobile, tablet, desktop
- **Hamburger menu** for mobile

## 🎨 Design

- **Theme**: Dark, futuristic, minimal — with bold typography
- **Font**: Syne (display) + DM Sans (body)
- **Accent**: Electric blue (#5b7fff) + Purple (#8b5cf6)
- **Background**: Deep dark (#080b12) with subtle grid + floating orbs

## 🚀 Setup

1. Extract all files to a folder
2. Open `index.html` in any browser
3. For best experience, serve via a local server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```

## 📬 Contact Form

The contact form uses [Web3Forms](https://web3forms.com). 
Your access key is already configured. No backend required.

## 📝 Customize

- Replace name/info in all HTML files
- Update social links in footer and contact page
- Replace `about-img-placeholder` with your real photo
- Update project links in `projects.html`
- Replace Web3Forms access key with your own at [web3forms.com](https://web3forms.com)
